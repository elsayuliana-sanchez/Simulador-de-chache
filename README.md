Simulador de caché 

Este proyecto consiste en un simulador de memoria caché desarrollado en Python.
El programa permite realizar búsquedas de personas por ciudad y simula el funcionamiento de una memoria caché, registrando los aciertos (hits) y fallos (misses).

Tecnologías utilizadas:
- Python
- Tkinter
  
Funcionalidades:
- Buscar personas por ciudad.
- Simular el almacenamiento de información en caché.
- Mostrar la información almacenada en la caché.
- Registrar los hits y misses.
- Interfaz gráfica para realizar las búsquedas.
